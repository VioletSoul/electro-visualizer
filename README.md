# electro-visualizer
Electro Visualizer V3 is a single-page, browser-based engineering playground for visualizing and calculating common electrical quantities — from basic Ohm’s law to complex impedance, RLC resonance, Bode-style plots and phasor waveforms.

The app is built as a standalone HTML file with no backend or build step: open it in any modern browser and you get an interactive UI with sections for DC/AC calculations, complex numbers, RLC circuits, first-order filters and resistive dividers, each with its own input panel, result cards, sweep tables and charts powered by Chart.js.
